# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not acceptable in issues, pull requests or any other project space.

If you see or experience behaviour that breaks these rules, report it to the maintainers through GitHub's private reporting on the repository's **Security** tab. Reports are kept confidential.
